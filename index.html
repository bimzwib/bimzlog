Setup Guide

How to Install BimzTools

  1. 1 Install pyRevit first — it's required before anything else. Download it from the official site:
  2. pyrevitlabs.io
  3. 2 Confirm the install — open Revit and check that a new pyRevit tab appears in the Ribbon. This confirms pyRevit is working before you continue.
  4. 3 Download and unzip BimzTools using the download button above, then extract it anywhere on your machine.
  5. 4 Run the installer — inside the extracted folder, find and run Install_BimzTools.bat
  6. Once it finishes, BimzTools will load automatically inside Revit — ready to use.

Setup Guide

How to Install the LISP Tools

  1. 1 Copy the LISP files to any fixed folder on your machine.
  2. 2 Open AutoCAD.
  3. 3 Type the command APPLOAD and press Enter.
  4. 4 Click the Contents button inside Startup Suite if you want the LISP files to load automatically every time AutoCAD opens.
  5. 5 Click Add and choose the required LISP files, then click Close and Load.
  6. After loading, type the LISP command name in the command line and press Enter — ready to use.

Setup Guide

How to Install BIMZ NAVIS TOOLS

  1. 1 Make sure Navisworks is fully closed before you start.
  2. 2 Download the tool's folder from the Google Drive link above.
  3. 3 Open the downloaded folder — inside each tool's folder you'll find a file called Install
  4. 4 Run the Install file — as long as Navisworks is closed, the tool will install itself automatically.
  5. 5 Open Navisworks — the BIMZ NAVIS TOOLS tab will appear automatically in the Ribbon, ready to use.
  6. Repeat the same Install step for each tool you download. All 4 tools are available directly inside the company — for internal BIM coordination workflows. Work by ZIAD ANTER.
